## ✨ Overview

**DivineIndia** is a React-based web application that allows users to explore famous Indian temples categorized by states.  
It focuses on delivering a smooth user experience with clean navigation and structured data presentation.

This project is built to strengthen frontend development skills while showcasing India’s rich cultural heritage in a digital format.

---

## 🛕 Features

- 📍 State-wise temple exploration  
- 🛕 Detailed temple information (name, deity, location)  
- ⚡ Fast and responsive UI  
- 🔄 Smooth page navigation using React Router  
- 📱 Mobile-friendly design  
- 🎨 Clean and modern interface  

---

## 🧠 Tech Stack

- React.js  
- React Router DOM  
- Vite  
- JavaScript (ES6+)  
- CSS3

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
